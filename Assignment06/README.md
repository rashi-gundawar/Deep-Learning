# Assignment 06 – Tomato Leaf Disease Detection using CNN

## Objective
To build a Convolutional Neural Network (CNN) for classifying tomato leaf images into different disease categories.

## Dataset
Tomato Leaf Dataset for Disease Detection
The dataset contains images of tomato leaves belonging to different disease classes.

## Tasks Performed
- Downloaded the dataset using KaggleHub
- Loaded and explored the image dataset
- Resized images to 128 × 128 pixels
- Split the dataset into training and validation sets
- Applied data augmentation
- Normalized image pixel values
- Built a CNN model
- Trained the CNN model
- Evaluated model performance
- Visualized training and validation accuracy
- Visualized training and validation loss
- Generated predictions for sample images
- Saved the trained model

## Tools and Technologies
- Python
- Google Colab
- TensorFlow
- Keras
- NumPy
- Matplotlib
- KaggleHub

## Result
The trained CNN model was evaluated using validation accuracy and loss. Sample predictions were also visualized to understand the classification performance.
