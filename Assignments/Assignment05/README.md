# Assignment 05 – RNN vs LSTM vs GRU Sequence Classification

## Objective
To implement and compare Simple RNN, LSTM, and GRU models for sequence classification using the IMDB movie review dataset.

## Dataset
IMDB Movie Reviews Dataset
The dataset contains movie reviews classified into two sentiment categories:
- Positive
- Negative

## Tasks Performed
- Loaded the IMDB dataset
- Limited the vocabulary size
- Padded the review sequences
- Built a Simple RNN model
- Built an LSTM model
- Built a GRU model
- Trained all three models
- Evaluated model performance
- Compared accuracy, precision, recall, and F1-score
- Plotted validation accuracy and loss
- Generated classification reports
- Saved the comparison results

## Models Used
- Simple RNN
- LSTM
- GRU

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score

## Tools and Technologies
- Python
- Google Colab
- TensorFlow
- Keras
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Result
The three sequence models were trained and evaluated on the IMDB sentiment classification task. Their performance was compared using different evaluation metrics and visualizations.
