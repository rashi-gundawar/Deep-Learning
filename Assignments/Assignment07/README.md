# Assignment 07 – Transfer Learning

## Objective
To implement transfer learning for image classification using pre-trained CNN models and compare their performance.

## Dataset
CIFAR-10 Image Classification Dataset

## Models Used
- AlexNet
- VGG16
- ResNet50
- EfficientNetB0

## Tasks Performed
- Loaded the CIFAR-10 dataset
- Preprocessed and normalized the images
- Split the dataset into training and validation sets
- Applied transfer learning using pre-trained CNN models
- Frozen the feature extraction layers
- Replaced the final classification layers
- Trained and validated the models
- Evaluated model performance
- Compared the models using different metrics
- Generated classification reports and confusion matrices

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Training Time
