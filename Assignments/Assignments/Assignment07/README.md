# Assignment 07 – Transfer Learning

## Objective
To implement transfer learning for image classification using pre-trained CNN models and compare their performance.

## Dataset
Intel Image Classification Dataset

## Models Used
- AlexNet
- VGG16
- ResNet50
- EfficientNetB0

## Tasks Performed
- Loaded and preprocessed the image dataset
- Resized and normalized images
- Split the dataset into training and validation sets
- Loaded pre-trained CNN models
- Frozen the pre-trained feature extraction layers
- Replaced the final classification layer
- Trained each model
- Evaluated model performance
- Compared the models using different performance metrics

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Training Time

## Tools Used
- Python
- Google Colab
- PyTorch
- Torchvision
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
