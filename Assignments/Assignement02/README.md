# Assignment 02 – MLP Classification using Iris Dataset

## Objective
To design and implement a Multilayer Perceptron (MLP) for classification of the Iris dataset and evaluate its performance using accuracy and a confusion matrix.

## Dataset
Iris Dataset


### Input Features

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Tasks Performed

- Loaded the Iris dataset
- Explored the dataset and feature information
- Checked missing values and class distribution
- Divided the dataset into training and testing sets
- Standardized the input features using StandardScaler
- Built a Multilayer Perceptron classifier
- Trained the MLP model
- Generated predictions on the test data
- Calculated classification accuracy
- Generated a classification report
- Generated and visualized the confusion matrix
- Plotted the training loss
- Tested individual samples
- Displayed the final classification results

## Evaluation Metrics

The model is evaluated using:
- Accuracy
- Confusion Matrix
- Precision
- Recall
- F1-Score
