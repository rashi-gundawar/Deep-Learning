# Deep-Learning

This repository contains a collection of Deep Learning assignments, experiments, implementations, and course materials covering fundamental and advanced concepts in Machine Learning and Deep Learning. The assignments explore neural networks, CNNs, RNNs, LSTMs, GRUs, transfer learning, Transformers, and various real-world applications.

## 📂 Repository Structure

| Folder | Description |
|--------|-------------|
| [Assignment 1](./Assignment%201/README.md) | MNIST data preparation and TensorFlow low-level CNN implementation. |

| [Assignment 3](./Assignment%203/README.md) | MNIST forward and backpropagation experiment comparing learning rates and epochs. |
| [Assignment 4](./Assignment%204/README.md) | Time-series forecasting of synthetic daily sales using LSTM. |

| [Assignment 7](./Assignment%207/README.md) | SVM/KNN credit-default classification and transfer-learning report. |
| [Assignment 8](./Assignment%208/README.md) | Sentiment analysis using pretrained BERT on the SST-2 dataset. |
| [Assignment 9](./Assignment%209/README.md) | Pretrained Vision Transformer and ResNet18 comparison on CIFAR-10. |
