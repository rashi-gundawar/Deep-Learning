# Deep-Learning

This repository contains a collection of Deep Learning assignments, experiments, implementations, and course materials covering fundamental and advanced concepts in Machine Learning and Deep Learning. The assignments explore neural networks, CNNs, RNNs, LSTMs, GRUs, transfer learning, Transformers, and various real-world applications.
